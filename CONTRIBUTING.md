# Contributing

1. Install Node.js, pnpm, Rust and the Tauri prerequisites for your platform.
2. Create a focused branch and preserve unrelated workspace changes.
3. Run `pnpm check` before opening a pull request.
4. For UI changes, attach same-viewport before/after screenshots and update `docs/design-qa.md`.
5. Do not add Cloud, account, telemetry or remote execution features to the open-source core without an accepted design proposal.
